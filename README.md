# stray

Kleines Komfort-Addon für **World of Warcraft: Forever**.

## Funktionen

- `/stray` öffnet und schließt ein Fenster mit schnellen Einstellungen. Esc schließt es ebenfalls, und das Fenster lässt sich verschieben.
- **Automatisch plündern** schaltet die Blizzard-Einstellung um, ohne dass du ins Optionsmenü musst.
- **Schnell plündern** nimmt die Beute sofort, ohne auf das Beutefenster zu warten. Das geht nur, wenn „Automatisch plündern“ an ist. Gegenstände, die eine Bestätigung brauchen, fragt WoW weiterhin ab. Mit gedrückter Shift-Taste plünderst du wie gewohnt manuell.

Hinweis: Hat ein anderes Addon (z. B. Leatrix Plus) ebenfalls „Faster Looting“ aktiv, nutze nur eins von beiden.

## Installation

Den Ordner `stray` nach `World of Warcraft\_forever_\Interface\AddOns\` kopieren und das Spiel neu starten.
